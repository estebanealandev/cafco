# CAFCO

Landing page for CAFCO, artisanal concrete-and-teak coffee pour-overs handmade
in Costa Rica. Built with [Astro](https://astro.build), Tailwind CSS v4, and
TypeScript in strict mode — a fully static site with no client-side framework.

## Stack

- **[Astro](https://astro.build)** — static site generation, i18n routing, image optimization
- **Tailwind CSS v4** (`@tailwindcss/vite`) plus hand-written component CSS driven by design tokens
- **TypeScript**, strict mode
- **[Lenis](https://lenis.darkroom.engineering/)** for smooth scrolling; all other interactivity (nav, mobile menu, catalog filter, locale switcher, scroll reveals) is plain TypeScript with no UI framework
- **[Fontsource](https://fontsource.org/)** for self-hosted Google Fonts (Instrument Serif / Instrument Sans)
- **Vitest** for unit tests
- **ESLint** (`@antfu/eslint-config`) + Prettier, Husky, lint-staged, Commitlint

## Getting started

```bash
pnpm install
pnpm dev       # http://localhost:4321
```

Other scripts:

```bash
pnpm build       # production build to dist/
pnpm preview     # preview the production build
pnpm typecheck   # astro check
pnpm lint        # eslint .
pnpm format      # prettier --write .
pnpm check       # typecheck + lint + format check (CI gate)
pnpm test        # vitest run
```

## Project structure

```
src/
├── assets/          # local images, processed by astro:assets
├── components/
│   ├── icons/
│   ├── layout/      # nav, footer, mobile menu, locale switcher, site head
│   └── sections/     # one component per landing-page section
├── data/            # typed, non-translated data (site constants, product catalog)
├── i18n/
│   ├── config.ts     # locale list, default locale
│   ├── messages.ts    # typed translation loader
│   └── messages/      # es.json (source of truth) / en / de / fr
├── layouts/
├── pages/
│   ├── index.astro          # redirects to the default locale
│   └── [locale]/index.astro # the actual page, one static build per locale
├── scripts/          # vanilla TS behind each <script> tag
└── styles/           # tokens.css + base.css + one file per section
```

## Internationalization

Locales: `es` (default), `en`, `de`, `fr` — all URL-prefixed (`/es/`, `/en/`,
…), configured in `astro.config.mjs`. Adding a locale means adding it to
`src/i18n/config.ts` and creating the matching `src/i18n/messages/<locale>.json`
(TypeScript will error if its shape doesn't match `es.json`).

## Image placeholders

This project was migrated from a previous stack whose product/hero photography
lived on hosts (Wix, an R2 bucket) that were unreachable from the sandbox this
migration was built in. All image imports already point at their real, final
local paths under `src/assets/` — but the current file contents are
placeholders generated by `scripts/generate-placeholders.mjs`.

To swap in the real photos, run from an environment with network access to the
original hosts:

```bash
node scripts/fetch-legacy-assets.mjs
```

This overwrites the placeholders in place at the same paths — no code changes
needed. `public/og-image.png` and `public/cafco-logo.svg` have no legacy
source (they're net-new SEO/brand assets) and should be replaced independently
whenever real designs exist.

## Deployment

`pnpm build` outputs a fully static site to `dist/`, deployable to any static
host (Netlify, Cloudflare Pages, GitHub Pages, Vercel's static output, S3 +
CDN, etc.) — no server or adapter required.

Before going live, confirm `SITE_URL` in `src/data/site.ts` matches the real
production domain — it drives canonical URLs, Open Graph tags, hreflang
alternates, the sitemap, and structured data.
